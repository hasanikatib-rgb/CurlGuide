# CurlGuide — deployable web app

This is a real Gradio web app. To make it available at a public URL:

1. Create a new GitHub repository and upload the files in this folder (not the ZIP itself).
2. In Render.com, choose **New > Blueprint**, connect that repository, and apply the `render.yaml` configuration.
3. Wait for the build to complete, then open the `.onrender.com` URL Render provides.

The app requires server-side Python and **cannot** run by double-clicking an HTML file. The free service may sleep when idle.

**Important:** The existing nine-class model scored only 17.8% test accuracy and is not dependable. It does not recognize 4A–4C. These appear only as a guide under the name "Very Curly". Do not use the predictions as established facts.

Uploaded photos are processed by the hosting server. Review Render's privacy and data-handling settings before sharing the site publicly.
